# Graph_4

Модели для Blender по теме нефтепромысловой инфраструктуры.

## Существующие модели

- `pipeline.py` / `pipeline.blend` — участок нефтепровода на Н-образных опорах.
- `pump_script.py` / `oil_pump.blend` — упрощённая станция-качалка.

## Комплексная модель месторождения

- `field_model.py` — генератор обобщённой low-poly сцены нефтяного месторождения.
- `field_development_complex.blend` — итоговый файл Blender, создаётся запуском скрипта.
- `Assets/` — Unity-совместимый каркас проекта: модель FBX, материалы, runtime/editor C#-скрипты, terrain/bootstrap.
- `README/UNITY_INSTRUCTIONS.md` — точные инструкции открытия в Unity и клавиши управления.

Состав сцены:

- добывающие скважины со станками-качалками и насосной арматурой;
- нагнетательная скважина;
- ДНС — дожимная насосная станция;
- УПСВ — установка предварительного сброса воды;
- УПН — установка подготовки нефти;
- БКНС и КНС;
- система связных трубопроводов: эмульсия/нефть, вода закачки, товарная нефть, газовая линия;
- трубные 90°-повороты выполнены четвертями тора, без шаровых стыков;
- резервуары стоят на фундаментах/юбках, горизонтальные аппараты — на седловых опорах;
- насосные блоки имеют рамы, входные/напорные коллекторы и фланцевые подключения;
- станки-качалки уточнены по структуре `pump_script.py`: A-рама, H-балансир, horsehead, кривошипы, сегментные противовесы, шатуны;
- конусные маркеры потока заменены плоскими стрелками-табличками;
- ДНС явно соединена с верхней газовой трубой, а КНС имеет низкую внутреннюю обвязку и опоры;
- резервуары, сепараторы, насосные блоки, дороги, подписи и стрелки потоков.

Запуск:

```bash
blender --background --python field_model.py
```

После запуска рядом со скриптом появится:

```text
field_development_complex.blend
```
